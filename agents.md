# Open USP — Universal Service Protocol

## Purpose
Base protocol for connecting AI agents to real-world services. Defines discovery, contracts, messages, security (Security-by-Design), and extensions. UDP (open-udp-v0) is an open protocol for Last Mile, compatible with USP.
