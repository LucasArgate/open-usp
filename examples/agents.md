# Open USP — Examples

## Purpose
Implementation examples for the Universal Service Protocol: basic, advanced, and contract examples.

## Context
- **basic/** — Hello World, request/response, events, error handling.
- **advanced/** — Service discovery, authentication, distributed tracing, rate limiting, caching.
- **contracts/** — Example contracts (user, payment, notification, analytics services).

## Retrieval
Reference `../manifest/` for spec. Examples are in development; use manifest README and specification for implementation details.
